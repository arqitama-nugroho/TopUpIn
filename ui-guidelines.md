# TopUpIn UI Guidelines

## Theme

TopUpIn is a game top-up marketplace web application inspired by platforms such as Itemku and Codashop.

Design goals:

- Clean
- Simple
- Modern
- Easy to navigate
- Mobile-friendly

Avoid excessive animations, complex layouts, and unnecessary visual elements.

## Design Principles

- Keep interfaces simple and intuitive.
- Prioritize usability over visual complexity.
- Maintain consistency across all pages.
- Use cards and tables instead of complex layouts.
- Minimize decorative elements.
- Ensure readability on all screen sizes.
- Keep the user journey clear and straightforward.
