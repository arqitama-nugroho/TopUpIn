# Project Overview

You will build a **TopUpin Web Application**.

TopUpin is a web application that allows users to browse game top-up products, manage their accounts, purchase products, and view transaction history.

The application is designed to be simple, responsive, and easy to use.

---

- Hero section
- Featured products
- Navigation bar
- Footer
